## Что такое верификация

**Верификация** — это процесс подтверждения личности пользователя через проверку документов модератором.

### Преимущества верификации:
- ✅ Повышение доверия на платформе
- ✅ Снижение мошенничества
- ✅ Улучшение качества услуг
- ✅ Бейдж "Verified ✓" на профиле

### Статусы верификации:
- **`pending`** — документы ожидают проверки
- **`approved`** — документы одобрены (пользователь верифицирован)
- **`rejected`** — документы отклонены

## Доступ к документам пользователя

### Шаг 1: Войдите в Sharetribe Console
1. Откройте https://console.sharetribe.com
2. Войдите с вашими учетными данными
3. Выберите ваш маркетплейс (YouDo)

### Шаг 2: Найдите пользователя
1. В меню слева выберите **Users** → **Manage**
2. Используйте поиск для нахождения пользователя:
   - По email
   - По имени
   - По ID пользователя

### Шаг 3: Откройте профиль пользователя
1. Кликните на имя пользователя
2. Нажмите **Edit user**

### Шаг 4: Просмотрите загруженные документы
1. Прокрутите вниз до секции **Protected data**
2. Найдите поле `verificationDocuments`
3. Вы увидите структуру:

```json
{
  "verificationDocuments": [
    {
      "id": "68f14ac6-e4de-4f22-b4d0-fdfb5def2b48",
      "type": "passport",
      "uploadedAt": "2025-10-16T12:30:45.123Z",
      "status": "pending"
    },
    {
      "id": "68f14ac6-e4de-4f22-b4d0-fdfb5def2b49",
      "type": "passport",
      "uploadedAt": "2025-10-16T12:30:45.456Z",
      "status": "pending"
```

### Шаг 5: Откройте изображения документов

⚠️ **ВАЖНО:** В Sharetribe Console нет прямого раздела для просмотра изображений по ID. Используйте API.

#### 🔧 Способ 1: Через API (ЕДИНСТВЕННЫЙ РАБОЧИЙ)

**Шаг 5.1: Получите Client Credentials**

1. Откройте **[Sharetribe Console](https://console.sharetribe.com)**
2. Перейдите: **Build** → **Applications** → **Add new**
3. Создайте приложение с именем "Verification Moderator"
4. Скопируйте **Client ID** и **Client secret**

**Шаг 5.2: Получите токен доступа**

**macOS/Linux:**
```bash
export CLIENT_ID="your-client-id"
export CLIENT_SECRET="your-client-secret"

# Получить токен
TOKEN=$(curl -X POST "https://flex-api.sharetribe.com/v1/auth/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials&client_id=${CLIENT_ID}&client_secret=${CLIENT_SECRET}" \
  | jq -r '.access_token')

echo "Token: $TOKEN"
```

**Windows (PowerShell):**
```powershell
$CLIENT_ID = "your-client-id"
$CLIENT_SECRET = "your-client-secret"

# Получить токен
$Body = @{
    grant_type = "client_credentials"
    client_id = $CLIENT_ID
    client_secret = $CLIENT_SECRET
}

$Response = Invoke-RestMethod -Uri "https://flex-api.sharetribe.com/v1/auth/token" `
  -Method Post -Body $Body -ContentType "application/x-www-form-urlencoded"

$TOKEN = $Response.access_token
Write-Host "Token: $TOKEN"
```

**Шаг 5.3: Получите URL изображения**

**macOS/Linux:**
```bash
export IMAGE_ID="68f1f533-06f1-4a6f-a1a7-84440f8e3ebf"

# Получить изображение
curl "https://flex-api.sharetribe.com/v1/api/images/${IMAGE_ID}" \
  -H "Authorization: Bearer ${TOKEN}" \
  | jq -r '.data.attributes.variants."scaled-large".url'
```

**Windows (PowerShell):**
```powershell
$IMAGE_ID = "68f1f533-06f1-4a6f-a1a7-84440f8e3ebf"

$Response = Invoke-RestMethod -Uri "https://flex-api.sharetribe.com/v1/api/images/$IMAGE_ID" `
  -Headers @{"Authorization"="Bearer $TOKEN"}

$ImageURL = $Response.data.attributes.variants.'scaled-large'.url
Write-Host "Image URL: $ImageURL"
Start-Process $ImageURL  # Откроет в браузере
```

**Результат:** Вы получите прямой URL изображения, который можно открыть в браузере.

## Проверка документов

### Что проверять:

#### 1. **Читаемость**
- ✅ Фото четкое, без размытия
- ✅ Текст читается полностью
- ✅ Нет засветов или теней

#### 2. **Подлинность**
- ✅ Документ выглядит настоящим (не скан, не фотошоп)
- ✅ Видны все элементы защиты (голограммы, водяные знаки)
- ✅ Нет признаков подделки

#### 3. **Соответствие**
- ✅ Имя и фамилия совпадают с данными профиля
- ✅ Фото в документе похоже на фото профиля (если есть)
- ✅ Документ актуален (не истек срок действия)

#### 4. **Тип документа**
- ✅ Паспорт: все страницы с фото и данными
- ✅ Emirates ID: обе стороны
- ✅ Водительские права: обе стороны
- ✅ Бизнес лицензия: все страницы с реквизитами

### Критерии для отклонения:
- ❌ Документ нечитаем
- ❌ Фото низкого качества
- ❌ Истек срок действия
- ❌ Признаки подделки
- ❌ Не совпадает с данными профиля
- ❌ Загружен не тот документ

## Одобрение верификации

### Если документы прошли проверку:

#### Шаг 1: Обновите **Profile metadata**
В секции **Profile metadata** (тип — JSON) убедитесь, что есть булево поле:

```
Key: isVerified
Type: Boolean
Value: true
```

#### Шаг 2: **Public data** не трогайте
`isVerified` в **Public data** сайт и приложение не учитывают: эти данные
пользователь может изменить сам. Значок зависит только от **Profile metadata**,
которую меняет только оператор.

#### Шаг 3: Обновите статус в **Protected data**
Измените статус документов с `pending` на `approved`:

```json
{
  "verificationDocuments": [
    {
      "id": "68f14ac6-e4de-4f22-b4d0-fdfb5def2b48",
      "type": "passport",
      "uploadedAt": "2025-10-16T12:30:45.123Z",
      "status": "approved"
    }
  ],
  "verificationNotes": "Документы проверены и одобрены 2025-10-16"
}
```

#### Шаг 4: Сохраните изменения
Нажмите **Save changes** внизу страницы.

### Результат:
- ✅ На профиле пользователя появится бейдж **"Verified ✓"**
- ✅ Бейдж отображается на:
  - Странице профиля (десктоп и мобильная)
  - Карточках заданий (ListingCard)
  - Странице задания (UserCard)

## Отклонение верификации

### Если документы не прошли проверку:

#### Шаг 1: НЕ устанавливайте `isVerified`
Не добавляйте `isVerified: true` в **Profile metadata**.

#### Шаг 2: Обновите статус в **Protected data**
Измените статус документов на `rejected` и добавьте причину:

```json
{
  "verificationDocuments": [
    {
      "id": "68f14ac6-e4de-4f22-b4d0-fdfb5def2b48",
      "type": "passport",
      "uploadedAt": "2025-10-16T12:30:45.123Z",
      "status": "rejected"
    }
  ],
  "verificationNotes": "Отклонено: фото нечитаемо, истек срок действия документа"
}
```

#### Шаг 3: Сохраните изменения
Нажмите **Save changes**.

#### Шаг 4: Уведомите пользователя
Отправьте email пользователю с объяснением причины отклонения и инструкцией по повторной загрузке.

## Типы документов

### 1. **Passport (Паспорт)**
- ✅ Загружены все страницы с фото и данными
- ✅ Читаются ФИО, дата рождения, номер паспорта
- ✅ Фото владельца четкое

### 2. **ID Card / Emirates ID**
- ✅ Обе стороны карты
- ✅ Читаются ФИО, дата рождения, номер ID
- ✅ Фото владельца четкое
- ✅ Срок действия актуален

### 3. **Driver's License (Водительские права)**
- ✅ Обе стороны прав
- ✅ Читаются ФИО, дата рождения, номер прав
- ✅ Фото владельца четкое
- ✅ Срок действия актуален

### 4. **Business License (Бизнес лицензия)**
- ✅ Официальный документ регистрации компании
- ✅ Читается название компании, реквизиты
- ✅ Указан владелец/директор
- ✅ Срок действия актуален (если применимо)

## Безопасность данных

### ⚠️ ВАЖНО:

1. **Документы хранятся в `protectedData`**
   - ❌ Никогда не храните документы в `publicData`
   - ✅ `protectedData` доступен только владельцу и операторам

2. **Статус верификации в `metadata`**
   - ✅ Только флаг `isVerified: true/false`, его ставит только оператор
   - ❌ Не храните его в `publicData`: её пользователь меняет сам
   - ❌ Никогда не публикуйте ID документов, номера, личные данные

3. **Конфиденциальность**
   - ✅ Документы видят только модераторы
   - ✅ Удаляйте заметки с личными данными из `verificationNotes`
   - ✅ После проверки можно удалить изображения (опционально)

4. **GDPR / Data Protection**
   - ✅ По запросу пользователя документы должны быть удалены
   - ✅ Храните документы только необходимое время

## Часто задаваемые вопросы (FAQ)

### Q: Сколько времени занимает верификация?
**A:** Обычно 24-48 часов. В пиковые периоды до 72 часов.

### Q: Может ли пользователь загрузить документы повторно?
**A:** Да. Если статус `rejected` или `pending`, пользователь может загрузить новые документы через `/account/verification`.

### Q: Как отозвать верификацию?
**A:** Удалите или измените `isVerified` на `false` в **Profile metadata**. Измените статус на `revoked` в **Protected data** с указанием причины в `verificationNotes`.

### Q: Можно ли верифицировать компанию?
**A:** Да. Используйте `"verificationType": "company"` и требуйте бизнес-лицензию.

### Q: Что делать, если документ на иностранном языке?
**A:** Запросите перевод или документ с латиницей (например, Emirates ID).
