Название: `Барахолка Дубай`

```

https://t.me/dubaibaraholka/1/182939

Барахолка Дубай — сообщество для частных обьявлений в ОАЭ
```

### Проблемы

1. **Опечатка в главном слове.** «обьявлений» вместо «объявлений» — поисковик не засчитает
   как совпадение по запросу «объявления».
2. **Правила ведут в никуда.** `t.me/dubaibaraholka/1/182939` — сообщение внутри группы,
   для краулера такой страницы не существует.
3. **Первая строка пустая по смыслу.** «Покупка и продажа личных вещей» не содержит
   ни «Дубай», ни «объявления», ни «барахолка».

### Рекомендуемое описание

```
Барахолка Дубай: бесплатные объявления — купить и продать б/у мебель, технику, одежду, детское. Частные продавцы, без комиссии.

📌 Правила: TELEGRAPH_URL
🛠 Мастера в ОАЭ: youdu.ae
📬 Реклама: @usernameyagmur
```

`TELEGRAPH_URL` замени на адрес страницы с правилами.

**Лимит:** 255 символов. Без ссылки текст занимает ~193 символа, на адрес остаётся ~62.
Если адрес telegra.ph длиннее, убирай по порядку: «детское», потом «без комиссии»,
потом строку про мастеров.

## Общие рекомендации для обеих групп

### Порядок публикации на telegra.ph

Адрес страницы telegra.ph фиксируется в момент первой публикации и не меняется при
переименовании. Чтобы адрес был коротким:

1. Публикуем с коротким заголовком: `Правила барахолки Дубай`
2. Копируем адрес (будет ~48 символов)
3. Редактируем заголовок на полный: `Правила барахолки Дубай — как публиковать объявления`

### Закреплённое сообщение

В закреплённом сообщении должны быть ссылки на:
- telegra.ph с правилами
- telegra.ph с памяткой о безопасной сделке
- youdu.ae/baraholka-dubai

Закреплённое сообщение видно на странице `t.me/` без входа в Telegram —
это одно из немногих мест, куда краулер реально дотягивается.

### Что изменилось после правок

Первые сто символов описания теперь содержат «барахолка», «Дубай», «объявления»,
«купить», «продать», «б/у» — и всё читается как нормальное предложение.
Ссылка на правила ведёт на индексируемую страницу вместо мёртвой ссылки внутри группы.
